## ✨ Creative Feature — Beyond the Code

**Beyond the Code** is an interactive section that introduces visitors to my interests outside programming.

Visitors are invited to select one of three interactive cards:

- 📚 **Books** — Discover my interest in reading.
- 🎮 **Games** — Explore my enjoyment of gaming.
- 🎵 **Music** — Learn about my interest in playing music.

Each selection reveals a personal story through an interactive interface with smooth transitions.

The feature includes visible interaction hints, keyboard support, selected states, a reset option, and reduced-motion accessibility support.

**Purpose:** To demonstrate that my interests extend beyond programming and to combine my creativity with frontend development.

I improved these through targeted changes and local browser testing.
